SniffnDetect is a Python 3 tool I published on GitHub. The public README describes it as sniffing network traffic and identifying SYN flood, SYN-ACK flood, ICMP smurf, and ping-of-death patterns, then trying to identify the source. Version 2 adds a local web UI on port 5000, built with threads, the Quart framework, and WebSockets. The README says it needs to run as root on Linux or as Administrator on Windows.

The repository is [priyamharsh14/SniffnDetect](https://github.com/priyamharsh14/SniffnDetect).
