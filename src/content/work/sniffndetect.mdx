SniffnDetect is an open-source DDoS detector written in Python 3. The public README describes it as sniffing network traffic and identifying SYN flood, SYN-ACK flood, ICMP smurf, and ping-of-death patterns, then trying to identify the source. Version 2 adds a local web UI built with threads, the Quart framework, and WebSockets. It listens on port 5000, and the README says it needs to run as root on Linux or as Administrator on Windows.

Source: [github.com/priyamharsh14/SniffnDetect](https://github.com/priyamharsh14/SniffnDetect).
