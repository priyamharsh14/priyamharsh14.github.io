Prawler is an open-source Python 3 library for finding working proxies. The public README says it collects HTTP, SOCKS4, and SOCKS5 proxies, can filter by anonymity level (transparent, anonymous, elite) and country code, and can return a random proxy, a list, JSON, or a text file. It is installable with `pip install Prawler`.

Source: [github.com/priyamharsh14/Prawler](https://github.com/priyamharsh14/Prawler).
